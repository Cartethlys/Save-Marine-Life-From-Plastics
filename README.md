# Save Marine Life from Plastic

A multi-page school website on SDG 14: Life Below Water. Use the top menu or the Next buttons to move between pages.

## Files

- index.html: the page content (HTML)
- style.css: the design and layout (CSS)
- script.js: the interactive parts (JavaScript): page switching, hover charts, quiz, checklist, feedback form, scrolling background

Keep all three files in the same folder.

## How to use

Double-click index.html to open it in any web browser.

## Before submitting

Check every statistic against its source, replace the placeholder with your own references, and add a local Penang example on the Solutions page. Hover over each box to check the extra information and graphs.

## Sending feedback to your Gmail

Open script.js in a text editor and search for "FEEDBACK SETTINGS".

Option A (simple): replace yourname@gmail.com with your Gmail address. When someone submits feedback, their email app opens with the message ready and addressed to you. They must press send.

Option B (automatic): create a free form at formspree.io using your Gmail, copy your form link, and paste it into FORM_ENDPOINT. Feedback then arrives in your Gmail without the visitor sending anything. This needs the website to be opened online (for example hosted on GitHub Pages).
